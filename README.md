# Análise de Dados com Big Data & PySpark (NYC Taxi 2024)

Este repositório contém o notebook acadêmico desenvolvido para a consolidação de conceitos teóricos e práticos sobre Big Data e processamento distribuído com PySpark.

## Tecnologias e Conceitos Utilizados
- **Ferramenta:** Google Colab
- **Framework:** Apache Spark (PySpark)
- **Engine:** Catalyst Optimizer & Tungsten
- **Dataset:** NYC Taxi Trip Data (Amostra de 4 milhões de linhas)
- **Conceitos:** Transformations vs Actions, Lazy Evaluation, Narrow vs Wide Dependencies (Shuffle), Inferência de Schema vs StructType.

## Conteúdo
O notebook contempla o guia teórico com questões conceituais e a resolução prática de 10 exercícios abrangendo filtragem, agregações, manipulação de datas e joins distribuídos.
